Genome Sequencing / Genetic Variant Classification
Oct. 2025–Dec. 2025

Built a machine-learning and data-engineering pipeline for genetic variant classification using Python, DuckDB, pandas, PyTorch, and scikit-learn.

Combined the Humsavar and dbNSFP 5.3a datasets, performing data joining, transformation, preprocessing, and exploratory analysis before using the resulting dataset to train neural-network classification models.

The project demonstrated how improving the underlying dataset and feature pipeline could materially improve downstream model performance rather than relying solely on changes to model architecture.

Best statistic:
- Improved model F1 from approximately 0.40 to 0.70

Resume bullets:
- Constructed a pipeline conjoining Humsavar and dbNSFP using DuckDB and pandas, improving F1 scores by 70%.
- Contributed data exploration using seaborn, pandas, and Matplotlib, increasing data readability for model tuning.
- Developed a neural network learner using Python, PyTorch, pandas, and scikit-learn with roughly 70% F1 score.
- Stack: Python, DuckDB, pandas, PyTorch, scikit-learn.
