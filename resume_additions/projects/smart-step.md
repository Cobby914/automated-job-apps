Smart Step — Smart White Cane
Oct. 2025–Dec. 2025

Developed an assistive embedded system designed to help visually impaired users detect obstacles and elevation changes.

Built the device using C, PlatformIO, Arduino/ESP32, ultrasonic sensors, time-of-flight sensing, and AWS. Sensor readings were processed to identify incoming objects and terrain changes and trigger feedback for the user.

Also worked directly with physical hardware debugging and developed cloud/Bluetooth functionality through the ESP32.

Best statistics:
- Approximately 80% obstacle/elevation detection accuracy
- Approximately 90% accuracy for the Bluetooth/voice feature

Note: Exclude the latency number until verified. One resume version lists 30 seconds, which may be a unit error.

Resume bullets:
- Created a smart white cane detecting elevation changes and incoming objects using T.O.F and ultrasonic sensors.
- Developed a buzzer feedback system for blind and deaf users from sensor inputs with low-latency physical testing.
- Relayed data from ESP32 to AWS cloud for a Bluetooth voice feature with approximately 90% accuracy in trials.
- Stack: C, PlatformIO, Arduino, ESP32, AWS.
