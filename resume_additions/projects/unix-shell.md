Unix Shell

- fork
- exec

- pipe
- dup2
- signals
- file descriptors
- input/output redirection
- multi-process pipelines

The project required managing parent/child process behavior, connecting command pipelines through file descriptors, redirecting standard input/output, and correctly cleaning up child processes.
