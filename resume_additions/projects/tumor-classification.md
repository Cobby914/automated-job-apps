Tumor Classification from Medical Scans
Oct. 2025–Dec. 2025

Developed a deep-learning pipeline for classifying tumors from medical scan data using Python, PyTorch, scikit-learn, and pandas.

Built a residual neural-network architecture and performed systematic hyperparameter experimentation to improve classification performance. Used grid-search-style experimentation and visualization to compare model configurations.

Also implemented Grad-CAM to investigate which portions of medical images influenced model predictions, adding an explainability component to the project rather than evaluating only classification accuracy.

Best statistics:
- Achieved approximately 99% F1
- Model optimization improved performance approximately 30%
- Grad-CAM analysis reached approximately 0.67 correlation

Resume bullets:
- Created a residual neural network using scikit-learn, PyTorch, and Python with an F1 score of roughly 99%.
- Implemented a grid search using pandas, Matplotlib, and PyTorch, optimizing the residual network by 30%.
- Implemented Grad-CAM for the residual neural network using PyTorch, reaching a spatial correlation of 0.67.
- Stack: Python, PyTorch, scikit-learn, pandas.
